📧 1. SMTP (Simple Mail Transfer Protocol)
NETWORK & AUTOMATION
개념: 인터넷망에서 이메일을 안전하고 신속하게 송신하는 국제 표준 네트워크 프로토콜입니다.
🛠️ WorkFree 프로젝트 적용 및 활용 방식:
  • 자율 보고서 메일 무인 발송: Power Automate Desktop 및 Python AI 에이전트가 매일 아침 전처리 완료한 일간 보고서(`Daily_Report.xlsx`)를 Outlook SMTP 서버를 통해 담당자에게 자동 발송합니다.
  • Zero-Touch 파이프라인 완성: 사람이 아침에 엑셀을 열고 메일을 보낼 필요 없이 에이전트가 메일 발송까지 마무리합니다.
// Python SMTP 이메일 자동 발송 코드 스니펫
import smtplib
from email.mime.multipart import MIMEMultipart
from email.mime.base import MIMEBase
from email import encoders

msg = MIMEMultipart()
msg['Subject'] = "[WorkFree] 일간 경영진 보고서 무인 자동 발송"
msg['From'] = "agent@workfreemarket.com"
msg['To'] = "manager@company.com"

# 엑셀 보고서 첨부 후 SMTP 전송
with open("C:\\Automation\\Reports\\Daily_Report.xlsx", "rb") as f:
    part = MIMEBase("application", "octet-stream")
    part.set_payload(f.read())
    encoders.encode_base64(part)
    msg.attach(part)

server = smtplib.SMTP('smtp.office365.com', 587)
server.starttls()
server.send_message(msg)
🤖 2. Google Gemini 2.0 Flash AI Engine
GENERATIVE AI
개념: Google DeepMind가 개발한 2세대 초고속 생성형 AI 모델로, 복잡한 코드 작성 및 요구사항 추론에 최적화되어 있습니다.
🛠️ WorkFree 프로젝트 적용 및 활용 방식:
  • 7대 핵심 수강 요소 인터뷰 분석: 헤더 오프셋, 컬럼 매핑, 예외 처리 등 7가지 사용자 요구사항을 전달받아 엑셀에 바로 심을 수 있는 완벽한 VBA 모듈(`AICOMPANY_MACRO.bas`)을 1초 만에 실시간 생성합니다.
  • 리본 메뉴 단추 심기 튜토리얼 연동: AI가 코드를 생성함과 동시에 사용자 엑셀 상단 리본 탭에 아이콘으로 심는 4단계 실전 튜토리얼까지 함께 렌더링합니다.
💳 3. PortOne V2 & Toss Payments PG API
PAYMENT GATEWAY
개념: 신용카드(신한, 하나, 삼성, 현대, KB국민 등) 및 간편결제(카카오페이, 토스페이, 네이버페이) 연동을 하나로 일원화하는 통합 결제 솔루션입니다.
🛠️ WorkFree 프로젝트 적용 및 활용 방식:
  • 5,000원 인강 및 40,000원 실강 전자결제 모달: 90% / 60% 얼리버드 앵커 가격이 적용된 전자결제 팝업창을 호출합니다.
  • 즉시 승인 & DB 동기화: 수강생이 결제를 마치면 0.1초 만에 Supabase DB에 결제 이력이 저장되며 10강 플레이어가 자동 오픈됩니다.
🗄️ 4. Supabase PostgreSQL & Auth Engine
DATABASE & AUTH
개념: PostgreSQL 기반의 오픈소스 클라우드 데이터베이스 및 실시간 사용자 인증 라이브러리입니다.
🛠️ WorkFree 프로젝트 적용 및 활용 방식:
  • 수강생 자격 영구 보존: 수강생이 재방문하더라도 결제 여부(`paid_status`), 결제 금액(`paid_amount`), 수강 완료 강의 리스트를 안전하게 동기화합니다.
⚙️ 5. Excel VBA & Windows COM Automation Engine
DESKTOP RPA ENGINE
개념: Windows OS 내부에서 엑셀 애플리케이션 객체(`Excel.Application`)를 백그라운드 무인(Hidden Mode) 제어하는 데스크톱 오토메이션 기술입니다.
🛠️ WorkFree 프로젝트 적용 및 활용 방식:
  • C:\Automation\ 백그라운드 가공: 엑셀 창을 켜지 않고 로우 데이터(`RAW_DATA.xlsx`) 10만 줄을 0.1초 만에 전처리하고 경영진 일간 보고서(`Daily_Report_20260730.xlsx`)를 자동 생성합니다.
  • 원클릭 윈도우 설치 배치 파일(`WorkFree_Agent_Installer.bat`): 어떤 PC에서든 더블클릭하면 3초 만에 전체 무인 파이프라인 환경이 완성됩니다.
